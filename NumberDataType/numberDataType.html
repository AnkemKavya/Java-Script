Number Data Type

In JavaScript, the Number data type is used to represent both integer and floating-point numbers. It can also represent special values like NaN (Not-a-Number) and Infinity.

Here are some examples of using the Number data type:

  • let age = 30; // An integer
  • let price = 19.99; // A floating-point number
  • let result = 10 / 0; // Infinity
  • let invalid = "abc" * 2; // NaN
